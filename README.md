# Tensu — Minecraft 1.21.1 Forge

Mod de absorção e evolução de habilidades por criaturas.

## Teclas
- G: abre o menu detalhado de habilidades.
- R: teleporte do Enderman, quando equipado.

## Evolução
Cada criatura possui progressão própria. A habilidade começa fraca e cresce aos poucos até o nível V.

## Habilidades
Coelho, vaca, galinha, lobo, tartaruga, peixes, golem de ferro, Enderman, aranha e zumbi.

## Build
O projeto inclui Gradle Wrapper e GitHub Actions. Use `./gradlew build` ou deixe o GitHub Actions compilar automaticamente.
