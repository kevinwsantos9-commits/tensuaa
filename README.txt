SISTEMA TENSURA - ABSORÇÃO
Minecraft 1.21.1 / Forge 52.1.16

Esta versão usa o Gradle Wrapper que veio do MDK oficial fornecido.
Java 21 é necessário.

NO PC:
    .\gradlew.bat build

NO GITHUB:
1. Envie todos os arquivos para um repositório.
2. Abra Actions.
3. Execute "Build Sistema Tensura".
4. Baixe o artefato "Sistema-Tensura-Absorcao".

Mecânicas iniciais:
- Coelho -> Super Pulo
- Vaca -> Resistência
- Galinha -> Queda Suave
- Lobo -> Instinto
- Tartaruga -> Defesa
- 10 derrotas = próximo nível, máximo nível 5.
- Tecla G abre o menu.
- Botões equipam/desequipam pelo comando do servidor.
- O progresso é salvo nos dados persistentes do jogador.

Observação: combinações de habilidades são a próxima camada do sistema; a base já está separada para receber esse módulo.
